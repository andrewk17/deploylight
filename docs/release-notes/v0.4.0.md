# Deploylight v0.4.0

Your Vercel and Cloudflare tokens are now stored in the macOS Keychain.
Earlier versions stored them unencrypted in the app’s preferences file.
Copies of that file may also exist in Time Machine or other backups, so
consider rotating your Vercel and Cloudflare tokens after updating.

Deploylight can now show an optional notice when an update is available.
You can turn off “Check for updates” in Preferences.
