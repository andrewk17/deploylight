# Deploylight v0.5.0

Deploylight now shows GitHub Actions runs next to your Vercel deployments
and Cloudflare Workers Builds. Use it for anything that deploys from a
workflow, including Workers shipped with `wrangler deploy`.

To set it up, open Preferences → Accounts and paste a fine-grained GitHub
token with Actions: Read-only on the repositories you want to watch. By
default, Deploylight shows workflows with “deploy” in their name or file
path. You can pick specific workflows instead.

Runs started by a release, and GitHub Pages builds, show as Production. So
do runs on the default branch started by a push, a manual run, a schedule
or another workflow. Other runs show as Preview.
