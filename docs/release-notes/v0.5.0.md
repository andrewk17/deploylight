# Deploylight v0.5.0

Deploylight now shows GitHub Actions runs alongside Vercel and Cloudflare.
Add a fine-grained GitHub token with read-only Actions access to the
repositories you want to watch.

Release runs and built-in GitHub Pages builds show as Production on any
branch. On the default branch, pushes, manual runs, scheduled runs, runs
triggered by another workflow, and dynamic runs also show as Production.
Other runs show as Preview.
